Error Code

CPU_EXCEPTION_PF

系統發生 Page Fault（頁面錯誤）。

這代表什麼？

當程式嘗試存取某個記憶體位置時， 系統發現該記憶體目前無法正常存取， 因此發生 Page Fault。

這並不一定代表硬體記憶體發生故障。 也可能是程式使用了無效的記憶體位置、 發生記憶體管理問題，或系統目前無法提供所需的記憶體頁面。

系統會怎麼處理？

發生 Page Fault 後，系統會嘗試處理這次記憶體存取。 如果問題可以安全恢復，系統可能會繼續正常執行。

如果系統無法安全處理這次錯誤， 可能會終止發生錯誤的程序， 或進入其他錯誤處理流程。

可能原因

常見原因包括程式錯誤、無效的記憶體存取、 指標使用錯誤、記憶體管理問題， 或系統元件發生異常。

我需要做什麼？

如果這個錯誤只發生一次， 可以先重新啟動裝置並確認問題是否再次出現。

如果問題持續發生，請記錄錯誤發生前的操作， 並將相關錯誤資訊提供給 AluaProjects 開發團隊。

錯誤資訊

系統可能會在 Serial 中記錄更詳細的錯誤資訊， 包含 ISR Error Code 以及其他除錯資訊。

如果需要協助排查問題， 建議一併提供發生錯誤時的 Serial Log。
