AluaPJUnder Error Code
CPU_EXCEPTION_PF

CPU Exception: Page Fault

CPU 發生頁面錯誤（Page Fault），並觸發系統的 ISR 例外處理機制。

錯誤說明

此錯誤表示 CPU 在執行程式時發生了 Page Fault，代表目前的程式嘗試存取 無法正常存取的記憶體區域。

系統會立即進入 ISR 例外處理系統， 嘗試判斷並處理此錯誤。

如果錯誤無法安全恢復，系統可能會終止 發生錯誤的程序，或進入相應的錯誤處理流程。

常見原因

此錯誤可能由無效記憶體存取、指標錯誤、 記憶體管理錯誤、頁面映射問題或其他系統程式問題造成。

建議處理方式

此錯誤極有可能與系統程式或核心元件有關。 如果錯誤可以重現，建議將錯誤情況回報給 AluaProjects 開發團隊。

詳細崩潰資訊會記錄於 Serial， 包含 ISR Error Code 等除錯資訊。 如需協助排查問題，請提供相關 Serial Log。
