Error Code

COMERR_ACPI_HPET_INIT_FAILED

系統無法初始化 HPET（High Precision Event Timer）。

這代表什麼？

HPET（High Precision Event Timer）是一種硬體計時器， 可以提供高精度的時間事件。

XNKernel 的部分計時功能會使用 HPET。 其中包括 Timer 與 Sleep 等服務， 用於讓系統能夠在指定的時間點處理工作， 或讓程序暫停一段時間後再繼續執行。

因此，如果 HPET 無法正常初始化， 可能會影響 XNKernel 的計時相關功能。

為什麼會發生？

此錯誤可能表示系統無法正常取得或初始化 平台提供的 HPET。

問題可能與系統韌體提供的 ACPI 資訊、 HPET 硬體資源，或系統與平台之間的相容性有關。

會造成什麼影響？

HPET 是 XNKernel 計時服務的重要硬體計時來源之一。 如果 HPET 無法使用， 依賴相關計時功能的系統服務可能無法正常運作。

特別是 Timer 與 Sleep 服務可能受到影響， 進而造成部分程序的等待時間或時間事件無法正常處理。

這是硬體故障嗎？

不一定。

此錯誤表示系統無法正常初始化 HPET， 但單獨出現此錯誤並不能直接判定硬體已經損壞。

問題也可能來自系統韌體、ACPI 設定， 或系統與平台之間的相容性問題。

我需要做什麼？

如果這個錯誤只是偶發發生， 可以先重新啟動裝置並確認問題是否再次出現。

如果問題持續發生， 建議確認裝置韌體是否為最新版本， 並確認相關 ACPI 與硬體設定是否正常。

如果問題仍然存在， 請記錄錯誤畫面以及相關 Serial Log， 並提供給 AluaProjects 開發團隊。

系統會怎麼處理？

由於 HPET 對 XNKernel 的計時服務較為重要， 如果系統無法確認 HPET 可以正常使用， 可能無法安全地繼續初始化相關計時功能。

系統會依照目前的錯誤處理流程進行處理， 以避免在計時功能狀態不正確的情況下繼續執行。

錯誤代碼

COMERR_ACPI_HPET_INIT_FAILED

COMERR 表示「相容性錯誤」。 ACPI_HPET_INIT_FAILED 表示 HPET 初始化失敗。
