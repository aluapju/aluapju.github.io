Error Code

KERNEL_END

系統核心已停止執行。

這代表什麼？

系統核心在執行過程中遇到了無法安全繼續處理的狀況。 為了避免系統在錯誤狀態下繼續執行， 系統已停止核心的正常運作。

如果系統繼續執行，可能會發生非法記憶體存取、 資料損壞或其他不可預期的問題。 因此系統會直接進入崩潰狀態。

我需要做什麼？

如果這只是偶發發生，請重新啟動裝置， 並確認問題是否再次出現。

如果重新啟動後仍然發生相同錯誤， 請記錄畫面上顯示的錯誤資訊， 以及系統的 Kernel Log 或 Serial Log。

如果問題持續發生

如果裝置持續出現 KERNEL_END， 代表系統可能存在需要進一步處理的問題。

請將相關錯誤資訊提供給 AluaProjects 開發團隊， 以協助確認造成系統停止的原因。

錯誤代碼

KERNEL_END

此代碼用於表示系統核心已無法安全繼續執行， 因此主動停止系統運作。
