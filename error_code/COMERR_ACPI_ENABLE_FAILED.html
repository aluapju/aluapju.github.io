Error Code

COMERR_ACPI_ENABLE_FAILED

系統無法啟用 ACPI。

這代表什麼？

ACPI 是作業系統與平台韌體之間的重要介面， 用於提供硬體組態、電源管理以及其他平台相關功能。

在系統取得並初始化必要的 ACPI 資訊後， 還需要進一步啟用 ACPI 功能。 此錯誤表示 XNKernel 在這個階段無法成功啟用 ACPI。

因此，系統可能無法可靠地使用後續依賴 ACPI 的平台功能。

為什麼會發生？

此錯誤可能表示系統韌體沒有正確回應 ACPI 啟用要求，或目前平台的 ACPI 狀態 無法被系統正常切換。

問題也可能與韌體實作、ACPI 設定， 或系統與平台之間的相容性有關。

會造成什麼影響？

如果 ACPI 無法啟用， XNKernel 可能無法正常使用部分 平台管理與電源管理功能。

此外，其他依賴 ACPI 初始化結果的系統功能 也可能無法正常啟動。

這是硬體故障嗎？

不一定。

此錯誤表示 ACPI 無法成功啟用， 但單獨出現此錯誤並不能直接判定硬體已經損壞。

問題可能來自系統韌體、ACPI 實作、 平台設定，或系統與裝置之間的相容性問題。

我需要做什麼？

如果這個錯誤只是偶發發生， 可以先重新啟動裝置並確認問題是否再次出現。

如果問題持續發生， 建議確認裝置韌體是否為最新版本， 並確認相關平台與 ACPI 設定是否正常。

如果問題仍然存在， 請記錄錯誤畫面以及相關 Serial Log， 並提供給 AluaProjects 開發團隊。

系統會怎麼處理？

ACPI 是 XNKernel 初始化平台環境的重要部分。 如果 ACPI 無法啟用， 系統可能無法確認平台管理功能處於正常狀態。

為避免在平台管理環境不完整的情況下繼續執行， 系統會依照目前的錯誤處理流程進行處理。

錯誤代碼

COMERR_ACPI_ENABLE_FAILED

COMERR 表示「相容性錯誤」。 ACPI_ENABLE_FAILED 表示 ACPI 啟用失敗。
