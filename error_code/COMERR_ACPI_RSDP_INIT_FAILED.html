Error Code

COMERR_ACPI_RSDP_INIT_FAILED

系統無法初始化 ACPI 的 RSDP（Root System Description Pointer）。

這代表什麼？

ACPI 是由系統韌體提供的一套標準介面， 用於讓作業系統取得與硬體組態、電源管理及其他平台資訊相關的資料。

RSDP（Root System Description Pointer） 是 ACPI 初始化過程中的重要資訊。 系統會透過 RSDP 找到後續的 ACPI 系統描述表， 例如 RSDT 或 XSDT。

如果系統無法正確取得或初始化 RSDP， 就無法可靠地繼續取得這些 ACPI 資訊。

為什麼會發生？

此錯誤可能表示系統韌體提供的 ACPI 資訊無法被正常取得、 識別或驗證。

例如 ACPI 資訊可能不存在、內容不符合預期， 或相關資料的驗證沒有通過。

在使用 UEFI 的裝置上， RSDP 的位置通常會由韌體透過 EFI System Table 所提供的 Configuration Table 傳遞給作業系統。 在傳統 BIOS 平台上，系統則可以依照 ACPI 規格搜尋 RSDP。:contentReference[oaicite:1]{index=1}

這是硬體故障嗎？

不一定。

此錯誤主要表示系統無法正常取得或使用平台提供的 ACPI 基礎資訊，並不能單獨代表硬體本身已經損壞。

問題可能與系統韌體、ACPI 資訊或系統與平台之間的相容性有關。

我需要做什麼？

如果這個錯誤只是偶發發生， 可以先重新啟動裝置並確認問題是否再次出現。

如果裝置每次啟動時都出現相同錯誤， 建議確認裝置的韌體與 ACPI 設定是否正常， 並確認是否有可用的韌體更新。

如果問題持續發生， 請將錯誤畫面以及相關 Serial Log 提供給 AluaProjects 開發團隊。

系統會怎麼處理？

由於 ACPI 是系統初始化與平台管理的重要基礎資訊， 如果 RSDP 無法正常初始化， 系統可能無法安全地繼續進行後續的 ACPI 初始化。

為避免在缺少必要平台資訊的情況下繼續執行， 系統可能會停止目前的初始化流程， 並進入相應的錯誤處理程序。

錯誤代碼

COMERR_ACPI_RSDP_INIT_FAILED

COMERR 表示「相容性錯誤」。 ACPI_RSDP_INIT_FAILED 表示 ACPI 的 RSDP 初始化失敗。
