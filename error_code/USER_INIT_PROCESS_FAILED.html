Error Code

USER_INIT_PROCESS_FAILED

使用者初始化程序啟動失敗。

這代表什麼？

系統無法成功啟動使用者初始化程序（init）。

init 是系統啟動後的重要初始化程序。 如果 init 無法正常啟動， 系統可能無法完成正常的啟動流程。

為什麼需要注意？

目前的 init 程式使用 XNC 格式。 XNC 是系統所使用的程式格式， 而 init.xnc 需要透過 XNC Loader 載入與執行。

因此，init 啟動失敗不一定代表 init 程式本身發生錯誤。

問題也可能來自 XNC Loader、 XNKernel 所提供的執行環境， 或其他與程式載入及執行相關的系統元件。

我需要做什麼？

此錯誤需要回報給 AluaProjects 開發團隊。

由於 init 的載入與執行涉及 XNC Loader 以及 XNKernel，因此需要進一步確認 實際發生問題的位置。

如果系統有提供相關錯誤訊息， 請記錄畫面上的資訊。

如果可以取得 Serial Log， 也請一併提供相關紀錄， 以協助確認問題究竟發生在 init、 XNC Loader 或 XNKernel。
