Error Code

COMERR_ACPI_FADT_INIT_FAILED

系統無法初始化 ACPI 的 FADT（Fixed ACPI Description Table）。

這代表什麼？

FADT（Fixed ACPI Description Table）是 ACPI 中的重要系統描述表之一。 它提供作業系統進行 ACPI 初始化時所需的固定硬體與平台資訊。

這些資訊與系統的 ACPI 功能以及電源管理等平台功能有關。 如果 FADT 無法正常初始化， 系統可能無法取得完整的 ACPI 平台資訊。

為什麼會發生？

此錯誤可能表示系統無法正常取得或驗證 FADT。

例如 FADT 內容可能不符合系統預期， 表格中的資訊可能無法正常使用， 或系統韌體提供的 ACPI 資訊與目前系統不相容。

這是硬體故障嗎？

不一定。

此錯誤主要表示 FADT 無法正常初始化， 並不能單獨證明裝置的硬體已經損壞。

問題可能與系統韌體、ACPI 表格內容， 或系統與平台之間的相容性有關。

我需要做什麼？

如果這個錯誤只是偶發發生， 可以先重新啟動裝置並確認問題是否再次出現。

如果問題持續發生， 建議確認裝置韌體是否為最新版本， 並確認韌體中的相關 ACPI 設定是否正常。

如果問題仍然存在， 請記錄錯誤畫面以及相關 Serial Log， 並提供給 AluaProjects 開發團隊。

系統會怎麼處理？

FADT 提供的資訊是 ACPI 初始化的重要組成部分。 如果 FADT 無法正常初始化， 系統可能無法安全地繼續進行後續的 ACPI 初始化。

為避免在平台資訊不完整或無法確認的情況下繼續執行， 系統可能會停止目前的初始化流程， 並進入相應的錯誤處理程序。

錯誤代碼

COMERR_ACPI_FADT_INIT_FAILED

COMERR 表示「相容性錯誤」。 ACPI_FADT_INIT_FAILED 表示 FADT 初始化失敗。
