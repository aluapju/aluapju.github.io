About AluaPJUnder™

AluaPJUnder™ is a technology development initiative under AluaProjects. Its primary focus is the research and development of operating systems, kernels, system software, development tools, and related technologies.

AluaPJUnder™ serves as the commercial name used for projects and technologies developed under the AluaProjects ecosystem. Its projects are developed with an emphasis on system independence, reliability, security, and long-term maintainability.

Projects and Technologies

AluaPJUnder™ includes multiple projects and technologies covering different layers of operating system development.

XNCOS

An operating system project within the AluaPJUnder™ ecosystem, providing the environment in which associated system components and user-space software operate.

XNKernel

The kernel project belonging to AluaProjects and, consequently, part of the AluaPJUnder™ ecosystem. It provides core system functionality and hardware- related services for XNCOS.

Restore

A system recovery environment designed to assist with system recovery and maintenance when normal system components cannot operate correctly.

XNC

A binary format and related technology used within the XNCOS ecosystem for system and user-space software.

XDL

The XN Dynamic Library technology used to provide dynamic library functionality within the system software ecosystem.

XNDS

A system data and interface technology forming part of the broader XNCOS development ecosystem.

Design Philosophy

AluaPJUnder™ does not assume that any operating system or software system can be completely free of vulnerabilities. Instead, its security approach focuses on reducing risk through multiple layers of protection.

  • Layered protection. Security is approached through multiple independent layers rather than relying on a single mechanism.
  • Risk reduction. Security mechanisms are designed to reduce the likelihood and impact of failures or attacks.
  • System independence. Core components are designed with clear boundaries and controlled dependencies whenever practical.
  • Maintainability. System architecture and interfaces are designed with long-term development and maintenance in mind.
  • Reliability. Recovery and defensive mechanisms are considered an integral part of system design rather than an afterthought.

Development

AluaPJUnder™ is developed as part of the AluaProjects ecosystem. Development covers operating system architecture, kernel development, system software, binary formats, development tools, recovery environments, and related technologies.

The projects are developed incrementally, with architectural decisions and system interfaces being refined as development progresses.
