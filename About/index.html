About AluaPJUnder™

AluaPJUnder™ is a commercial name under AluaProjects. It represents the development of operating systems, system software, development tools, and related technologies within the AluaProjects ecosystem.

The primary focus of AluaPJUnder™ is operating system development, including kernels, system components, recovery environments, binary formats, development tools, and other technologies required to build and maintain an operating system.

Projects

AluaPJUnder™ includes a number of projects and technologies developed under AluaProjects.

XNCOS is an operating system project within the AluaPJUnder™ ecosystem.

XNKernel is the kernel project belonging to AluaProjects and is therefore part of AluaPJUnder™.

Restore is a system recovery environment designed to provide recovery and maintenance capabilities when normal system components cannot operate correctly.

The ecosystem also includes technologies such as XNC, XDL, and XNDS, which support different parts of the operating system and software development environment.

Design Philosophy

AluaPJUnder™ does not assume that any operating system or software system can be completely free of vulnerabilities.

Instead, its approach is based on layered protection and risk reduction. Multiple defensive mechanisms are used so that a failure or vulnerability in one component does not necessarily compromise the entire system.

This philosophy places emphasis on system boundaries, component independence, recovery capabilities, reliability, and long-term maintainability.

Development

AluaPJUnder™ is developed as part of AluaProjects. Development covers operating systems, kernel architecture, system software, binary formats, development tools, recovery environments, and related system technologies.

Projects are developed incrementally, with their architecture and interfaces refined throughout development.
