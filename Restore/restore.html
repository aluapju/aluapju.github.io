Restore Steps

系統恢復處理步驟。

僅當裝置顯示六角形內部包含「!」的圖案時，才可進行恢復

開始前確認

⚠️ 請確認裝置目前處於 Restore 狀態

本恢復流程僅適用於裝置啟動後顯示 六角形內部包含「!」 的系統恢復狀態。

如果目前沒有 Restore Media， 請參閱

1. 準備 Restore Media

準備與目前裝置及系統版本相容的 Restore Media（恢復環境介質）。

Restore Media 必須包含可供裝置啟動的恢復環境， 以便在原本的系統環境無法正常運作時， 執行後續恢復操作。

2. 連接恢復環境介質

將 Restore Media 連接至需要恢復的裝置。

確認裝置可以識別該恢復介質， 並確保恢復過程中不要移除或中斷 Restore Media。

3. 從 Restore Media 啟動

使用裝置的啟動選項進入 Restore Media 所提供的恢復環境。

啟動完成後，確認目前執行的是恢復環境， 而不是原本發生問題的系統。

4. 掃描系統

在恢復環境中檢查目前系統的必要檔案與系統元件。

系統可能會檢查系統核心、驅動程式、 初始系統文件以及其他必要元件， 以判斷目前的系統環境是否可以被修復。

5. 執行系統恢復

根據掃描結果，恢復環境將嘗試修復或重新建立 遺失、損壞或無法正常使用的必要系統檔案。

恢復處理期間請勿關閉裝置， 也不要移除 Restore Media。

6. 完成恢復

當恢復程序完成後，依照恢復環境的提示重新啟動裝置。

若系統已恢復正常，裝置應能重新進入正常啟動流程。

恢復失敗

如果恢復完成後裝置仍然顯示六角形 「!」 狀態，表示系統問題可能仍然存在。

請重新確認 Restore Media 是否與目前裝置及系統版本相容， 並記錄恢復環境所提供的錯誤資訊。

如果問題仍然無法解決，建議將相關錯誤資訊 回報給 AluaProjects 開發團隊。

重要注意事項

只有在裝置顯示六角形內部包含「!」的 Restore 狀態時， 才應使用本恢復流程。

Restore Media 是恢復流程的必要環境。 在沒有恢復環境介質的情況下，不應嘗試執行本頁所述的恢復操作。

恢復過程中請保持裝置供電， 並避免中斷恢復環境的執行。
