Create Restore Media

使用 XNmakerestore 製作系統恢復環境介質。

Restore Media 用於啟動系統恢復環境

XNmakerestore

XNmakerestore 是用於建立 Restore Media（恢復環境介質）的工具。

製作完成後，可以使用該恢復介質啟動裝置， 並進入系統恢復環境以執行恢復操作。

1. 準備 USB

準備一個可以使用的 USB 儲存裝置， 並將其連接至需要製作 Restore Media 的電腦。

⚠️ 請注意 USB 內的資料

製作 Restore Media 時，XNmakerestore 將會對指定的 USB 進行寫入操作。

請確認被使用的 USB 資料已經備份，且 USB 內沒有需要保留的資料。

請特別確認指定的磁碟代號沒有選錯。 選擇錯誤的磁碟可能導致其他儲存裝置上的資料受到影響。

2. 確認 USB 磁碟代號

在執行 XNmakerestore 前， 請先確認系統分配給 USB 的磁碟代號。

不同作業系統使用的磁碟代號格式不同。 請確認指定的是 USB 裝置本身， 而不是電腦中的其他磁碟。

3. Linux

在 Linux 中，請先使用磁碟管理工具確認 USB 所使用的裝置代號。

確認完成後，在 XNmakerestore 所在的目錄執行：

sudo ./XNmakerestore -usb /dev/sdX

請將 /dev/sdX 替換成實際的 USB 裝置代號。

4. macOS

在 macOS 中，請先使用磁碟管理工具確認 USB 所使用的磁碟代號。

確認完成後，在 XNmakerestore 所在的目錄執行：

sudo ./XNmakerestore -usb /dev/diskX

請將 /dev/diskX 替換成實際的 USB 磁碟代號。

5. 等待製作完成

執行 XNmakerestore 後，請等待工具完成 Restore Media 的製作。

在製作過程中，請勿移除 USB， 也不要中斷 XNmakerestore 的執行。

製作完成後，USB 即可作為 Restore Media 使用。

6. 使用 Restore Media

將製作完成的 Restore Media 連接至需要恢復的裝置。

接著從 Restore Media 啟動裝置， 並進入恢復環境。

如果裝置目前顯示六角形內部包含 「!」 的 Restore 狀態， 即可依照 恢復處理步驟 進行後續操作。

注意事項

請務必確認 USB 磁碟代號。

XNmakerestore 使用指定的裝置建立 Restore Media。 請勿在未確認磁碟代號的情況下直接執行命令。

如果 USB 中仍有重要資料， 請先完成備份，再開始製作 Restore Media。

返回

完成 Restore Media 製作後， 可以返回 恢復處理步驟 繼續進行系統恢復。
